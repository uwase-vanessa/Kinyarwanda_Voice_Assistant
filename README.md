# Kinya Voice Assistant 🎙️🇷🇼

Kinya Voice Assistant is an intelligent speech recognition project designed to understand and transcribe Kinyarwanda audio using OpenAI's Whisper model through Hugging Face's `transformers` library. The assistant aims to bridge language accessibility in AI applications for Kinyarwanda speakers.

## 🔍 Features

- 🎧 Transcribes Kinyarwanda speech from audio files
- 🌍 Built using state-of-the-art Whisper model for multilingual ASR
- 🧠 Easily customizable for future intent detection and voice-command capabilities
